# Scorecards and trick-point restoration

The engine freezes a public scorecard when a hand settles, before any rule reveal or Endless round change. It records each player's hand awards, signed total, captured-card Game Point math, and reasons an active award had no recipient. A completed hand's card remains in the match state through the next automatic deal and roster change, so Scores and reconnect show the same result. Retained card identities are masked when the card is created. Other historical cards are stored as display labels rather than reusable deck IDs, so a later private deal does not expose that hand's card IDs in the public snapshot. Ending an unfinished hand records only completed-trick awards; it does not settle Pitch, Game Point, or Last Trick Bonus.

Points per Trick can enter a match only when No Points for Tricks currently controls ordinary trick scoring. Finite reveals skip the card until eligible; Endless draft options and authoritative choices use the same pre-insertion check. It has no ongoing prerequisite, because replacing No Points makes that prerequisite false. It is unavailable as a starting selection. The default one point per trick is unchanged.

Catalog version 7 records this eligibility change. Version 6 states are rejected by the catalog check, including any saved state loaded under an older catalog. Replay still uses recorded shuffle orders and actions, but requires the matching version 7 catalog; an old rule order could reveal a different card under the new eligibility policy. Production rooms remain in memory and end on a service restart, as before.
